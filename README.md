# 2048 数字合并小游戏

一个使用原生 HTML、CSS 和 JavaScript 编写的轻量级 2048 网页小游戏，无需安装依赖或启动构建工具。

## 开始游戏

直接在浏览器中打开项目里的 `index.html` 即可开始。也可以使用任意本地静态文件服务器托管项目目录。

## 游戏玩法

- 使用键盘 **方向键** 或 **W / A / S / D** 移动所有方块。
- 在手机或触控设备上，可在棋盘内向上、下、左、右滑动。
- 两个相同数字的方块相撞时会合并，数字相加；每次移动后会出现一个新的 2 或 4。
- 合成 2048 即可获胜。获胜后可以继续挑战，也可以开启新游戏。
- 棋盘被填满且无法再合并时，游戏结束。
- 点击 **新游戏** 可随时重新开始。最高分会保存在当前浏览器中。

## 项目文件

- `index.html`：游戏页面结构与中文说明。
- `styles.css`：棋盘、方块、弹窗和响应式样式。
- `game.js`：移动、合并、计分、触控操作与游戏状态逻辑。
- `README.md`：项目介绍与运行说明。

## 技术说明

游戏使用 4 × 4 数组保存棋盘状态；合并逻辑会确保每个方块在一次移动中最多合并一次。项目不依赖第三方库，支持桌面键盘和移动触控，并遵循系统的减少动态效果偏好。
